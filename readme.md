# ForbiddenWords

Приложение на C# Windows Forms для поиска запрещённых слов в текстовых файлах.

## Возможности

- Ввод запрещённых слов или загрузка из TXT.
- Поиск слов в выбранной папке.
- Копирование найденных файлов.
- Замена запрещённых слов на `*******`.
- Создание отчёта с результатами поиска.
- Отображение топ-10 запрещённых слов.
- Отображение прогресса работы.
- Пауза, продолжение и остановка поиска.
- Многопоточность и синхронизация.
- Запуск через командную строку.

## Технологии

- C#
- .NET 8
- Windows Forms
- Task, Mutex, CancellationToken, Parallel.ForEachAsync.

## Запуск

Сборка проекта:

cmd

```cmd
dotnet build
```

Запуск с интерфейсом:

cmd

```cmd
dotnet run
```

Запуск через консоль:

cmd

```cmd
dotnet bin\Release\net8.0-windows\ForbiddenWords.dll "C:\TestFiles" "C:\Results" password secret
```

## Результаты

Программа создаёт три элемента:

- `Original` — оригинальные найденные файлы.
- `Redacted` — файлы с заменёнными словами.
- `Report.txt` — отчёт с результатами поиска.

## Ограничения

Поиск и замена выполняются только в TXT-файлах.
